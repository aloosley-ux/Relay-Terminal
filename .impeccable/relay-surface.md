# Relay desktop — Operate

SCOPE: Replace Relay 2.1's visual world while preserving every workflow. Code-led implementation, editable Penpot components as the layout reference.
WORLD: A calm Windows instrument. Slate-blue Harbor, daylight Porcelain, warm Carbon, illustrated Tideland, restrained Frost. Segoe UI for controls, Cascadia Mono for shell content.
FIRST VIEWPORT: 1080 × 720 floating window. 44px frame, 39px session strip, 32px directory row, 28px status. Terminal owns the remaining space; navigator starts closed. Supporting workflows live behind native-sized controls.
SIGNATURE: Appearance Studio opens beside the actual shell; every preview updates that same terminal while its process and scrollback persist.
RESPONSIVE: Compact 760 × 500 uses temporary navigation; Studio dismisses navigation and leaves a usable terminal alongside the editor. F11 removes supporting chrome.
QUALITY BAR: Sharp text, consistent small controls, subtle selection, no dashboard cards or ornamental status. Contrast, keyboard access, resize and hidden-motion behaviour are native acceptance requirements.
FINISH: Native screenshots, meaningful appearance/state tests, existing regression and acceptance, fresh-context finish review and token-bearing documentation. seed: none (brief-pinned terminal-first direction).
