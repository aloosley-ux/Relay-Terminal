# Editable Relay 3 designs

The connected **ArcLane — Design Playground** file keeps all its existing pages. New page: **Relay 3 / Terminal & Appearance Studio**.

- File ID: `52a5041f-08a1-80f1-8008-c5171920d528`
- Page ID: `d87fc166-aa02-800a-8008-c7da6c4c52ec`
- Six editable boards: reusable controls, Harbor floating window, Porcelain compact window, live Appearance Studio, split sessions and terminal-only mode.
- Four reusable library components: secondary button, selected session, appearance scope, theme preview.
- Five palette token sets and one dimensions set: `relay3-harbor`, `relay3-porcelain`, `relay3-carbon`, `relay3-tideland`, `relay3-frost`, `relay3-dimensions`.
- 120 explicit token bindings; Penpot file validation returned no errors. A named version was saved after the new designs and bindings were added.

Designs contain editable text and vector shapes. Windows implementation uses installed Segoe UI; the editable Penpot reference uses Inter as its available interface substitute. The shell uses Cascadia Mono/Code with Consolas fallback. The [Studio SVG export](design/relay3-studio.svg) is an editable vector reference; the live Penpot file retains the components and token bindings.

The product system is documented in [DESIGN.md](../DESIGN.md), with motion, breakpoint and component-preview extensions in `.impeccable/design.json`. Native captures, rather than mockup exports, are the release screenshot evidence.
