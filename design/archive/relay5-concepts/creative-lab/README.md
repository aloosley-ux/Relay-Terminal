# Relay Terminal 5.0 / Creative Lab

Exploratory studies made in VectorCraft, EffectCraft and PhotoCraft. The four FigCraft concept boards (Signal, Ledger, Orbit and Caliper) were reviewed as references only; they remain unchanged and no direction was selected. Relay application code and approved assets were not modified.

## VectorCraft — Instrument glyphs
A compact four-mark language for Trace, Record, Orbit and Measure. The marks use original editable paths, circles and strokes with a shared geometry and restrained amber/mint accents.

- relay-instrument-glyphs.vectorcraft — editable source board
- relay-instrument-glyphs.svg — full board
- relay-instrument-glyphs-only.svg — vector marks only, cropped for reuse

Useful next: test legibility at 16/20/24 px, light surfaces and a color-blind-safe status palette; investigate Symbols and variable stroke profiles for a production family.

## EffectCraft — Command accepted
A 2.4-second, 30 fps study of an explicit Run action: button press, acknowledgement ripple, transient Running state, then attached success output. Transform and opacity properties use editable eased keyframes.

- relay-command-accepted.ecproj — editable project
- relay-command-accepted.gif — 600 x 350, 15 fps looping review
- relay-command-accepted.png — success-state still

Useful next: error/cancel/long-running variants, reduced-motion timing, and a tighter integration between status changes and the output panel.

## PhotoCraft — Graphite mica surface
A 1024 x 640 material study with an editable gradient base, low-frequency Clouds diffusion and a separate monochrome horizontal grain layer blended softly.

- relay-mica-surface.pcraft — editable layered source
- relay-mica-surface.png / relay-mica-surface.webp — flattened surface
- relay-grain-overlay.png — neutral grain map, isolated for palette-adaptive overlay use

The grain map can be aligned over a chosen surface color and composited with a low-opacity Soft Light treatment. It is a workspace overlay, not a seamless repeating tile. The neutral map separates texture from theme color; validate opacity and image size on real terminal text before using it broadly.

Useful next: compare 1x/2x compressed variants, confirm contrast over light and dark themes, and test reduced-size export on lower-powered hardware.
