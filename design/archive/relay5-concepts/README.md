## Review status

**Observed** means inspected in source or the live application. **Concept** means proposed in FigCraft. **Unknown** means it needs runtime, accessibility, or user verification. **Approved** remains reserved for product-owner sign-off. The screens are a design proposal, not proof of runtime parity, contrast compliance, or improved task performance.
