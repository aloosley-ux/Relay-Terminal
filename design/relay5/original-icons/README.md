# Retired Relay utility icon study

**Status:** concept archive; these custom utility icons are not used by the application.

Relay's UI icons use `lucide-react` throughout. The Switchline mark remains the separate, approved brand asset. The VectorCraft, FigCraft, comparison, and screenshot files in this directory document the retired custom icon direction and are retained as design history only.

Do not copy the archived SVGs into `src/` or treat their previews as current runtime evidence. Current icon and theme guidance is in [DESIGN.md](../../../DESIGN.md); the production component imports Lucide icons directly.
