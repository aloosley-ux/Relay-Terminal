# Relay 5.0 — Four Directions

Four editable visual proposals built in the existing FigCraft project. Each uses the same Relay scenario: two PowerShell sessions, a split pane, `lantern-api` on `feat/session-renewal`, a running Vite task on port 5173, discovered tasks, an observed external process, and an unknown local controller. The four concept pages also contain a developer workbench, full Appearance Studio, compact desktop layout, and command/paste/recovery states.

## A — Signal / Field Instrument

An operational instrument with a named navigation rail, workspace/session map, broad shell, and live telemetry edge. Strong at keeping project health and shell work in view. The fixed context edge and rail reduce terminal width, so dense labels and contrast need testing at common window sizes.

21st.dev discoveries: [Command Search by arihantcodes](https://21st.dev/@arihantcodes_1f7b8c4d/components/command-search) (demo 28888) for grouped, keyboard-oriented search; [Resizable by sean0205](https://21st.dev/@sean0205/components/resizable) (demo 4134) for a visible resize focus and keyboard affordance.

## B — Ledger / Editorial Working Field

A paper-toned project index and field notes frame an opaque, readable forest-green shell. The long-session hierarchy and scoped workspace context feel calm and legible. Its central shell is narrower, and the pale chrome may not suit every preference; the full palette model should be checked in a dark application theme.

21st.dev discoveries: [Tree View by ddoemonn](https://21st.dev/@ddoemonn/components/tree-view) (demo 23573) for navigable hierarchy and visible selection; [Command Menu by uvain](https://21st.dev/@uvain/components/command-menu-palette) (demo 33510) for grouped results, shortcut hints, and keyboard interaction.

## C — Orbit / Spatial Dock

Named floating work surfaces cluster around the terminal, with a separate activity dock. It keeps optional context out of the default shell view and gives projects, tasks, and runtime signals distinct spatial roles. Panels could obscure content or feel undiscoverable; docking, keyboard access, and a narrow-window fallback need usability testing.

21st.dev discoveries: [Floating Panel by klyv-ui](https://21st.dev/@klyv-ui/components/floating-panel) (demo 38475) for movable contextual surfaces; [Command by wensity](https://21st.dev/@wensity/components/command) (demo 31354) for grouped commands and nested navigation.

## D — Caliper / Machine Console

A measured register with strict rows and columns, explicit source/freshness labels, and visible process ownership. It makes task provenance and observe-only boundaries easy to compare. The formal density may feel clinical, and small labels need readability checks under scaling and accessibility settings.

21st.dev discoveries: [Minimisable Table by ruixen.ui](https://21st.dev/@ruixen.ui/components/minimisable-table) (demo 7473) for user-controlled data density; [File Tree by edwinvakayil](https://21st.dev/@edwinvakayil/components/file-tree) (demo 19150) for keyboard tree navigation and file selection.
