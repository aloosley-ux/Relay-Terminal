# Relay 5 creative directions review

The three directions are saved as editable FigCraft frames and exported as 1080 × 720 screens. The comparisons use the earlier FigCraft-only drafts at the same review size. Relay 4.0 is included as baseline context; its capture has an active shell and automation output visible, so it is not a clean visual benchmark.

## Strata

The screen keeps Relay's warm project rail and contour selection language, while carrying the PhotoCraft grain surface through the working field behind the terminal and context tray. Contour seams reinforce the selected session and task boundary. Small labels were raised for more reliable reading at 1080 × 720. The shell, task, Relay-owned process, port and inspect-only external controller remain explicit.

**Craft contribution:** PhotoCraft materially created the editable layered grain and relief source. It was saved as `.pcraft` before the flattened PNG surface export was made. FigCraft integrated that exported surface into the workspace and contains the editable screen. VectorCraft contour studies remain preserved, but were not used to create new material for this screen. EffectCraft was not used.

**Unresolved:** the screen is a static desktop proposal; compact-window behavior and the grain treatment across more appearance themes still need validation. The relief layers are hidden in the exported grain treatment and remain editable in the native PhotoCraft source.

## Counterpoint

The session score is part of the workspace itself. Two shell lines distinguish active focus from idle state, and the active line carries the `npm run dev` cue and time. The live terminal remains the main work area, with task, process, port and inspect-only status grouped beside it.

**Craft contribution:** FigCraft supplies the editable screen in the native project. No other Craft tool materially contributed to this direction.

**Unresolved:** score marks show a static snapshot, not a live timeline. Compact-window feasibility and keyboard interaction need product testing.

## Patchbay

The topology is part of the interface: solid connectors show project → session → owned task → process → port; a dashed branch marks the unknown observed controller. The left rail summarizes local entities and ownership, and the live shell stays visible below the map.

**Craft contribution:** FigCraft supplies the editable screen in the native project. The earlier VectorCraft topology study remains preserved but was not required for the integrated screen; EffectCraft and PhotoCraft were not used here.

**Unresolved:** the relationships and counts are representative static data. The graph needs live updates, keyboard access and a compact-window behavior check before implementation.
